# agent-robot — Agent 硬件终端（方案阶段）

软硬件结合项目：**Agent 本体运行在远端**，本终端硬件承担 **UI 层 + 操作层**（监听 / 发声 / 显示 / 交互）。

当前处于**方案讨论阶段**，仓库仅保留方案文档，暂不落地开发。

## 文档

- [`docs/architecture.md`](docs/architecture.md) — 架构设计（选型、硬件清单、学习路线、通信协议、扩展方向）

## 方案摘要

- 学习型 DIY 路线：不买集成开发板；ESP32-S3-WROOM-1-N16R8 + 分体模块（INMP441 麦 / MAX98357A 功放 / ST7789 屏）飞线验证 → 后期自绘 PCB + 3D 打印外壳
- 通信用 WebSocket（JSON 信令 + 二进制音频帧），协议以远端 Agent 实际实现为准
- 学习路线 L0~L6：点屏 → 收音 → 放音 → 飞线整机联调 → 画板打样焊接 → 3D 建模打印装配
