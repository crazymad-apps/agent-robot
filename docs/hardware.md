# 硬件部分：元器件选型

> 本文档是 agent-robot 方案的**硬件层**，聚焦元器件选型与硬件落地路径。
> 软件层（Agent 通信、交互）见 [`software.md`](software.md)，项目总览见 [`architecture.md`](architecture.md)。

## 1. 选型路线

**学习型 DIY**：全程以"学会硬件开发"为目标，不使用集成式开发板（如 ESP32-S3-BOX-3）。

```
阶段一 飞线验证：ESP32-S3 开发板 + 分体模块，杜邦线/飞线互连
阶段二 画板集成：KiCad/嘉立创 EDA 自绘原理图与 PCB → 打样 → 手工焊接
阶段三 外观装配：Fusion 360/FreeCAD 建模 → 3D 打印外壳 → 装配整机
```

## 2. 元器件选型表（BOM，飞线验证阶段）

| 部件 | 型号/方案 | 接口 | 参考价 | 选型理由 |

## 3. 引脚分配与接线（建议默认值）

> 以下为 ESP32-S3 DevKitC-1 的建议默认分配，可在 menuconfig 中调整；
> 避开 strapping 引脚（GPIO0/3/45/46）的启动态干扰，最终以实际板子丝印为准。

### 3.1 音频（I2S）

| 信号 | GPIO | 接往 |
|---|---|---|
| BCLK（SCK） | GPIO4 | INMP441 SCK、MAX98357A BCLK（可共享） |
| LRCLK（WS） | GPIO5 | INMP441 WS、MAX98357A LRC（可共享） |
| 麦克风数据 DIN | GPIO6 | INMP441 SD |
| 功放数据 DOUT | GPIO15 | MAX98357A DIN |
| 功放使能 | GPIO16 | MAX98357A SD（可选，拉高使能） |

### 3.2 屏幕（SPI，ST7789）

| 信号 | GPIO |
|---|---|
| SCLK | GPIO12 |
| MOSI | GPIO11 |
| CS | GPIO10 |
| DC | GPIO9 |
| RST | GPIO8 |
| 背光 BL | GPIO7（PWM 可调亮度） |

### 3.3 按键与灯环

| 信号 | GPIO | 说明 |
|---|---|---|
| 按键 1（PTT/唤醒） | GPIO0 | 注意 GPIO0 为 strapping/Boot，需上拉设计 |
| 按键 2（音量+） | GPIO1 | |
| 按键 3（音量-） | GPIO2 | |
| WS2812 数据 | GPIO48 | 单线协议，可串联灯环 |

### 3.4 飞线接线要点

- 所有模块**共地**（GND 连通），电源按 3.3V/5V 分开走。
- I2S 走线尽量短；麦克风远离功放与喇叭，避免串扰。
- 屏幕背光串限流电阻或用 PWM 驱动。

## 4. 电源方案

- **早期（飞线）**：USB 5V 供电，开发板自带稳压；外设共用 3.3V。
- **中期（电池，画板时并入）**：TP4056 充电模块 + 18650/锂电，逻辑 3.3V 稳压（AMS1117 或 DC-DC），功放独立供电。
- **后期（集成）**：自绘 PCB 上统一电源树，逻辑/功放分路。

## 5. 工具清单

| 状态 | 工具 | 说明 |
|---|---|---|
| 已有 | 万用表 | 通断、电压测量 |
| 飞线阶段 | 面包板 + 杜邦线 | 买带排针模块可免焊接 |
| 画板前购置（L4 前） | 电烙铁套装（+焊台） | 焊接自绘板、修模块 |

| 软件 | KiCad / 嘉立创 EDA；Fusion 360 / FreeCAD | 画板与建模 |
| 3D 打印 | 第三方代打（嘉立创/淘宝） | 自购打印机暂不规划 |

## 6. 外观与 3D 打印

- 外壳结构：屏幕斜置朝上、出声孔朝前、按键与灯环位预留。
- 关键开孔：屏幕窗口、喇叭出声孔、USB 编程口、麦克风拾音孔。
- 打印材料：PLA 起步即可；内部做喇叭音腔、固定柱。

## 7. 硬件学习路线

- **L0 点屏**：装 ESP-IDF，点亮 ST7789（LVGL Hello World）→ SPI、DMA
- **L1 收音**：INMP441 采集，串口打印音量/波形 → I2S、DMA
- **L2 放音**：MAX98357A 播放正弦波/录音回放 → 音频输出通路
- **L4 画板**：KiCad 原理图 → PCB 布局布线 → 嘉立创打样 → 焊接 → 板级验证
- **L5 外观**：3D 建模外壳 → 3D 打印 → 装配

## 8. 模块化原则

- 接口统一使用 I2S/SPI/UART/GPIO，**引脚在固件里可配置**，支持后续换主控/换屏幕。
- 预留双麦位、扩展排针，为"换板子做集成"（可选）留余地。
