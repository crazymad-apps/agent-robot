# S1.3 阶段计划

## 1. 范围

本阶段主动功能只使用单个 INMP441。功放始终保持 `SD=0`；屏幕可以保留接线，但不作为收音通过条件。

## 2. 顺序

1. **无声启动**：先关闭功放，再初始化 I2S RX。
2. **原始电平**：以 16kHz 单声道目标格式统计最小值、最大值、均值和 RMS。
3. **动态响应**：比较安静、正常说话、拍手三种情况下的电平变化。
4. **声道与位宽**：核对 `L/R` 选择、I2S slot 和 INMP441 有效位对齐。
5. **样本导出**：采集固定时长 PCM，生成标准 WAV 后在电脑端检查。

## 3. 停止条件

- `VDD` 不是 3.3V、`GND` 或 `L/R` 状态不明确。
- 原始样本持续全零、固定满量程或大量削波。
- 开发板、麦克风或导线异常发热，或 USB 反复断连。
- 任一步异常时先停止采样和供电，不带电移动杜邦线。

## 4. 完成判定

- 静音底噪有限，说话和拍手能产生明显且可重复的电平变化。
- 导出的 WAV 可播放、语音可辨识、无持续削波。
- 采样率、位宽、声道选择和转换方法均有记录。
