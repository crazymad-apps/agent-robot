# S2.0 基线与测试矩阵

## 1. 当前基线

| 项目 | 当前事实 | S2.0 动作 |
|---|---|---|
| 开发板 | ESP32-S3-DevKitC-1 v1.1 N8R8 | 保持不变 |
| 工具链 | ESP-IDF v6.0.2 + esp-sr 2.4.7 | 已通过依赖、模型、WakeNet 与 AFE API 构建/链接探针 |
| Flash / PSRAM | 8 MB / 8 MB | 已冻结 S2 分区；运行时 PSRAM 余量在 S2.2 实测 |
| 麦克风 | INMP441，GPIO4/5/6，L/R 接地 | 连续向 AFE/WakeNet 提供左槽 PCM |
| 功放 | MAX98357A，GPIO4/5/15/16 | 唤醒监听时关闭；播放时暂停 WakeNet |
| 屏幕 | ST7789 240×240，LVGL | 增加 Wi-Fi/唤醒状态投影 |
| PTT | GPIO21 低有效，30 ms 消抖 | 保留为唤醒失败时的回退入口 |
| 音频格式 | 16 kHz、单声道、PCM16 | 与 WakeNet 实际 feed 格式逐项核验 |
| Wi-Fi | 尚未实机连接 | 仅测试 2.4 GHz Station 模式 |
| 唤醒模型 | `wn9_nihaoxiaozhi_tts`（“你好小智”） | 已生成 291,042-byte 模型镜像；S2.2 首次烧录运行 |

## 2. 已冻结 Flash 布局

| 分区 | Offset | Size | 末地址 | 说明 |
|---|---:|---:|---:|---|
| nvs | `0x9000` | 24 KiB | `0xEFFF` | Wi-Fi 配置与系统 NVS；凭据不写普通日志 |
| phy_init | `0xF000` | 4 KiB | `0xFFFF` | PHY 初始化数据 |
| factory | `0x10000` | 2 MiB | `0x20FFFF` | S2 单镜像原型；OTA 留待后续阶段重审 |
| recording | `0x210000` | 256 KiB | `0x24FFFF` | 保留 S1 音频诊断样本 |
| model | `0x250000` | 1 MiB | `0x34FFFF` | ESP-SR 模型镜像 |
| 未分配 | `0x350000` | 4.6875 MiB | `0x7FFFFF` | 后续协议、诊断或 OTA 规划余量，不提前占用 |

构建工具已核验分区无重叠。完整 AFE/WakeNet 链接探针为 885,552 bytes，factory 分区余
1,211,600 bytes；模型镜像为 291,042 bytes，model 分区余 757,534 bytes。静态链接报告中
DIRAM 使用 157,329/341,760 bytes；模型实例、Wi-Fi 和任务栈的运行时高水位必须在 S2.2/S2.3
实机记录，不能由静态尺寸推断。

## 3. S2.1 Wi-Fi 测试

| 场景 | 预期证据 |
|---|---|
| 正确凭据冷启动 | 获得 IP，屏幕进入已连接状态，日志无密码 |
| AP 暂时关闭再恢复 | 有界退避重连，AP 恢复后自动取得地址 |
| 错误密码 | 明确错误状态，不高速无限重试，不泄漏密码 |
| 开发板重启 | 从受控持久配置恢复连接 |
| 网络抖动时 PTT | 本地录音回放不中断，LVGL 不阻塞 |

## 4. S2.2 WakeNet 测试

| 场景 | 原型门槛 |
|---|---|
| 0.5～1 米安静环境 | 20 次尝试至少成功 18 次 |
| 安静/日常背景声 | 连续观察至少 30 分钟，无误触发 |
| PTT 回退 | WakeNet 启用时 PTT 仍可触发本地闭环 |
| 播放阶段 | 暂停检测，播放结束后恢复监听 |
| 重启后 | 模型正常加载并回到监听状态 |

## 5. S2.3 最小共存与延期可靠性项

| 检查项 | 通过条件 |
|---|---|
| Wi-Fi + WakeNet + LVGL + I2S | 无看门狗、panic、黑屏或不可恢复 I2S 错误 |
| 内部堆/PSRAM | S2.3 仅记录启动与本地闭环后快照 |
| AP 断开/恢复 | WakeNet 和 PTT 保持本地可用，网络可自动恢复 |
| 严格可靠性 | 60 分钟长稳、任务栈/资源趋势与极端故障延期到 S4.0 PCB 输入冻结前 |

上述门槛只用于当前飞线原型的工程阶段门，不代表量产环境的唤醒率或误触发率承诺。
