# S2.1 阶段计划

## 执行顺序

1. 构建 `S2.1-wifi.1`，核验应用、模型、分区表和依赖锁文件。
2. 烧录前明确说明分区变化会使旧 recording 分区中的诊断录音不再可用；确认 S1.4 可重新构建恢复。
3. 首次启动确认屏幕显示 `WIFI SETUP`，串口不出现密码或未初始化异常；USB Serial/JTAG 双向命令链路已于 2026-08-22 实机通过。
4. 在本机串口执行 `wifi set`，只使用 2.4 GHz AP；连接后用 `wifi status` 核对 IP、RSSI 和计数。
5. 重启设备，确认从 NVS 恢复连接；再验证 AP 关闭/恢复和有界退避。
6. Wi-Fi 已连接和重试期间各执行至少一次 PTT 录音回放，确认音频与屏幕不被网络任务阻塞。
7. 执行 `wifi clear`，确认只清除 Wi-Fi 配置并回到 `WIFI SETUP`。

## 停止条件

- 串口或日志出现明文密码。
- 烧录后屏幕、PTT、收音或播放中的任何一项发生回归。
- 重连形成无延时循环、看门狗、panic 或持续黑屏。
- 只能连接 5 GHz SSID，现场没有可用的 2.4 GHz AP。
- NVS 初始化要求自动擦除整片数据；当前实现遇到该情况应报错并保留本地 PTT，而不是静默清除。

## 阶段门

- 正确凭据冷启动和重启均能获得 IP。
- AP 恢复后能自动重连，退避行为与记录一致。
- 错误或缺失配置可恢复，密码未进入仓库和普通日志。
- 联网与重试期间 PTT 本地闭环和屏幕保持可用。
