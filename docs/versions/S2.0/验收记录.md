## 构建偏差与风险

- ESP-SR 2.4.7 的变更记录将 IDF v6.0 支持标为 experimental；本项目因此精确锁定版本，不使用浮动范围。
- IDF 6.0.2 解析 ESP-SR Kconfig 时会提示多处 `default False` 不是标准布尔值，并按 `n` 处理；显式选择的
  `CONFIG_SR_WN_WN9_NIHAOXIAOZHI_TTS=y` 未受影响，模型和固件均成功生成。
- S2.0 证明的是“可构建、可链接、分区可容纳”，不是“已在实机唤醒”。模型加载、采样帧参数、动态堆、
  PSRAM、任务栈和识别率由 S2.2 实机验收。
- S2 分区会把 recording 从 `0x110000` 移到 `0x210000`。首次烧录新分区时原 S1 录音样本不保留；该样本
  属于可重新生成的诊断数据，但烧录前仍需向操作者明确说明。

## 阶段结论

- S2.0 阶段门通过：兼容组合、模型、分区、凭据边界和测试矩阵已冻结。

- 板上固件没有被本阶段覆盖，仍可按 S1.4 记录恢复。
