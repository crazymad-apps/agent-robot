# S1.4 阶段计划

## 执行顺序

1. 独立验证 GPIO21 低有效 PTT 输入和 30 ms 软件消抖。
2. 同时初始化屏幕、按键和板载 RGB，验证 `IDLE` 待机。
3. 按键触发提示音，顺序释放 I2S TX 后创建 I2S RX，录制 5 秒 PCM。
4. 释放 RX 后重新创建 TX，以带饱和保护的 +12 dB 增益回放录音。
5. 重复执行闭环，检查状态、削波、重启、I2S 超时和 LVGL 稳定性。
6. 记录音量加、音量减按键延期决定：飞线原型不再手焊两个贴片开关，GPIO1/2 保留到可靠载板或 PCB 验证。
7. 连续运行至少 30 分钟，完成阶段一接线、格式、功耗和问题清单冻结。

## 停止条件

- 屏幕花屏、LVGL 栈溢出或持续刷新阻塞。
- I2S 创建、读取、写入或通道切换失败。
- 录音期间功放未静音，或回放时出现明显持续中断、削波。
- 按键松开时 GPIO 仍为低，或一次动作产生多个消抖后事件。
- USB 供电下发生重启、棕断或器件异常发热。
