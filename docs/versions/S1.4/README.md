## 目标

- 同时运行 ST7789、INMP441、MAX98357A、4Ω 喇叭和低有效 PTT 按键。
- 实现 `idle / listening / playing / error` 本地状态机。
- 按键触发一次“提示音 → 录音 5 秒 → 本地回放”，不自动循环。
- 固化 GPIO、音频格式、增益、接线、已知问题和长时间运行证据。

## 当前结论

- 四脚贴片轻触开关已通过万用表确认触点分组，接为 `GPIO21↔GND`。
- 独立按键测试连续记录按下/松开事件，无消抖重复触发。
- `S1.4-loopback.1` 已连续完成 4 轮本地闭环并返回 `IDLE`，未重启或报错。
- 四轮录音均为 80,000 个样本，`4x`（约 +12 dB）回放增益的削波计数均为 0。
- 长稳最终时间戳为 3,814,237 ms（约 63 分 34 秒）；末轮录音回放成功并返回 `IDLE`，期间无重启、panic 或 I2S 错误。
- 阶段一硬件原型通过；下一步进入新的 S2 联网与本地唤醒验证，不接入临时语音 Host。
