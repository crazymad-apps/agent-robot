## 2. 结论

- 首次裸板运行曾因两个 2.5KB 音频缓冲同时位于 `app_main` 栈上触发栈溢出；缓冲移至静态内存后重新构建、烧录并完成上述 11 周期复验。
- 结论：MAX98357A、GPIO、I2S TX、`SD` 使能和 4Ω 单组线圈在 USB 低功率范围内通过。
- 高音量和连续播放不得引用本记录宣称通过；取得独立 5V 条件后需补验。
- 进入 S1.2：允许；按用户要求继续逐设备验证，切换屏幕前先断电拆除功放接线。
