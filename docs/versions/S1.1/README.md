| 项 | 内容 |
|---|---|

## 目标

- 单独验证 MAX98357A、其中一组实测 4Ω 的喇叭线圈和 I2S TX 链路。
- 先用极低数字幅度、短促间歇测试音确认接线，再逐步验证静音、音量与连续播放。
- 高音量或连续输出前，单独核对 5V 功放支路、电流能力和共地。

## 完成结果

1. `S1.1-audio.1/2` 已完成低幅度间歇测试音、静音和使能验证。
2. `S1.1-audio.3` 已完成 14 音符简单旋律播放，用户确认听感正常。
3. 当前没有已核对的独立 5V 电源，因此高音量与连续播放不执行，也不作为后续屏幕单设备验证的阻塞项。
