# S1.2 ST7789 接线表

> 所有接线必须在 USB 断开时完成。首次测试只连接屏幕；功放、麦克风和按键全部断开。

| ST7789 丝印 | DevKitC-1 | 功能 |
|---|---|---|
| `GND` | `G` | 共地 |
| `VCC` | `3V3` | 屏幕与逻辑 3.3V，不能接 5V |
| `SCL` | `GPIO12` | SPI SCLK，不是 I²C SCL |
| `SDA` | `GPIO11` | SPI MOSI，不是 I²C SDA |
| `RES` | `GPIO8` | 屏幕复位 |
| `DC` | `GPIO9` | 数据/命令选择 |
| `CS` | `GPIO10` | SPI 片选 |
| `BLK` | `3V3` | 首次固定开启背光；暂不接 GPIO7 |

## 上电前检查

- 功放的 `VIN/GND/BCLK/LRC/DIN/SD` 已全部从开发板断开。
- `VCC` 与 `BLK` 都接 3.3V，不能误接底部的 `5V`。
- `GND` 接开发板 `G`；SPI 信号与 `RES/DC/CS` 分别接到表中 GPIO。
- 屏幕背面无裸露导体压在面包板电源轨、开发板焊点或跳线上。
- 接线完成后先拍一张能同时看清屏幕丝印和开发板 GPIO 丝印的照片，再连接 USB。
