## 延期项

- 2026-08-21 用户决定跳过音量加、音量减的飞线手焊，原因是四脚贴片开关焊接风险较高。
- GPIO1/2 继续保留为音量键候选，但三键实物验证延至具备可靠载板、连接器或自绘 PCB 后执行。
- 当前固件使用固定 4x（约 +12 dB）回放增益并带饱和保护；该延期不影响 PTT 录音回放闭环和阶段一核心媒体 I/O 验收。

## 当前结论

- `S1.4-loopback.1` 已证明屏幕、PTT、麦克风、功放和喇叭可以同时连接并顺序工作。
- I2S TX/RX 共用 GPIO4/5，通过删除当前通道再创建另一方向的方式稳定切换。
- 飞线基线冻结为 USB 供电、16 kHz/单声道/PCM16、5 秒本地录音、固定 4x 回放增益和 GPIO21 低有效 PTT；接线以本阶段接线表为准。
- 已知限制：屏幕 `BLK` 固定接 3.3V；USB 供电下未做高功率连续放音；音量键延期到可靠载板或 PCB；首版交互保持半双工。
- 结论：S1.4 通过，阶段一硬件原型完成。允许进入新的 S2.0 联网与唤醒约束确认；原 Agent 联合设计顺延到 S3.0。
