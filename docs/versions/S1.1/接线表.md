# S1.1 功放与喇叭接线表

> 所有接线必须在 USB 与外部电源均断开时完成。首次测试只连接功放和喇叭，不连接显示屏、
> 麦克风或按键。首次仅允许低幅度间歇音，不进行高音量或连续播放。

## 功放输入

| MAX98357A 丝印 | DevKitC-1 | 功能 |
|---|---|---|
| `GND` | `G` | 共地 |
| `VIN` | `5V` | 首次低幅度测试使用开发板 USB 5V 支路 |
| `BCLK` | `GPIO4` | I2S 位时钟 |
| `LRC` | `GPIO5` | I2S 左右声道时钟 |
| `DIN` | `GPIO15` | I2S 音频数据 |
| `SD` | `GPIO16` | 功放使能；固件启动时保持低电平 |
| `GAIN` | 悬空 | 使用模块默认 9dB 增益 |

## 喇叭输出

- 已实测 4Ω 的同一组完整线对分别连接功放 `SPK+` 与 `SPK-`。
- 未使用的另一组两根线分别绝缘悬空，不能互接或接地。
- `SPK+`、`SPK-` 都不能接开发板 GND。

## 上电前检查

- 功放 `VIN` 接 `5V`，逻辑信号只接指定 GPIO，所有模块共地。
- 喇叭只使用已实测 4Ω 的一组线圈。
- `SPK+/-` 无裸铜短接，未使用线组已分别绝缘。
- 功放没有放在导电桌面或裸露金属上。
- 检查完成后才连接 USB；出现异常发热、焦味、破音、反复重启或 USB 断连时立即断电。

> 开发板 USB 5V 仅用于本阶段的低幅度、短促验证。高音量与连续播放必须先核对独立 5V
> 电源的额定电流、实际输出和共地，不得直接沿用本接法扩大音量。
