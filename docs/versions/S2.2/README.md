## 本阶段目标

- 连续采集 INMP441 左槽 16 kHz PCM16，并送入 ESP-SR 单麦 AFE/WakeNet。
- 使用已冻结模型 `wn9_nihaoxiaozhi_tts`，官方唤醒词为“你好小智”。
- 唤醒命中后暂停监听，发出本地提示音，完成一次 5 秒录音回放，再恢复监听。
- GPIO21 PTT 始终保留为等价手动触发入口；不接入 Agent、ASR、TTS 或 Runtime。

## 安全边界

- 播放与 WakeNet 监听不并行，避免提示音自触发和 RX/TX 争用同一 I2S 时钟线。
- 首版使用模型默认阈值，不在取得实测统计前宣称唤醒率。
- AFE 初始化或运行失败必须进入明确错误状态，不能静默退化为“已监听”。

## 当前产物

- 固件版本：`S2.2-wake.1`。
- app 大小：`0x16bd80` / `0x200000`，余 `0x94280`（29%）。
- 单麦输入格式 `M`，默认检测模式 `DET_MODE_90`，AFE 内存优先使用 PSRAM。
- 监听、提示/录音/回放按半双工顺序切换；PTT 与 WakeNet 共用本地闭环。
- 首轮测试为 17/20（85%）；固定 0.5 米、统一发音节奏的第二轮为 18/20（90%），已达唤醒率阶段门。
- GPIO21 PTT 回退闭环通过；专项观察 40 分钟无误触发、错误或重启证据。
