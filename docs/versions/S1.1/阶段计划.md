# S1.1 阶段计划

## 1. 范围

本阶段只验证 MAX98357A 和一组 4Ω 喇叭线圈，不连接显示屏、麦克风和按键。

## 2. 顺序

1. **无负载构建**：构建 I2S TX 固件，启动时保持 `SD=0`，确认引脚和时钟配置。
2. **低幅度间歇音**：断电接线后，播放短促低幅度音并穿插静音，确认有声且无异常。
3. **静音与使能**：验证 `SD` 关闭时无播放，启用后恢复。
4. **供电门**：高音量或连续播放前，核对独立 5V 供电的额定电流、实际电压和共地。
5. **已知 PCM**：逐级增加软件音量，记录噪声、失真、发热、复位和稳定性。

## 3. 停止条件

- 4Ω 线对身份、差分输出接法或共地不明确。
- 功放、喇叭、开发板或导线异常发热、有焦味、明显破音或 USB 反复断连。
- 未通过独立 5V 供电门前，不提高到高音量或连续播放。
- 任一步骤异常时立即断电，不连续改变接线和固件参数。

## 4. 完成判定

- 低幅度测试音可重复播放，静音间隔安静且无持续爆音。
- `SD` 使能和软件音量行为正确。
- 独立 5V 支路有实际核对证据后完成连续播放。
- 验收记录包含接线照片、日志、听感、供电和持续运行结果。
