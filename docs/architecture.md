# Agent 硬件终端（agent-robot）架构设计

## 0. 方案选型（已更新：学习型 DIY 路线）

**结论：终端采用 ESP32-S3 + 分体模块，全程以"学会硬件开发"为目标，不做集成式开发板。**

- **早期验证**：通用 ESP32-S3 开发板（如 DevKitC-1，仅引出引脚）＋ 分体模块，**飞线/杜邦线**连接。
- **中期集成**：用 KiCad/嘉立创 EDA 自绘原理图与 PCB，**打样 + 手工焊接**。
- **外观**：Fusion 360/FreeCAD 建模 + **3D 打印**外壳，装配整机。
- **可选环节**：后期可换主控板（如换更高算力 SoC）重新集成，因此接口设计保持模块化（I2S/SPI/UART 通用）。

### 分体硬件清单（飞线验证阶段）

| 部件 | 型号/方案 | 说明 |
|---|---|---|
| 主控 | **ESP32-S3-WROOM-1-N16R8**（先买 DevKitC-1 开发板，画板时焊 WROOM-1 模组） | 16MB Flash + 8MB PSRAM，音频缓冲/后续端侧 AI 够用；N=Flash、R=PSRAM |
| 麦克风 | **INMP441 模块 ×1（I2S MEMS，带排针）起步，预留第 2 麦位** | 单麦先跑通链路，后续加双麦学回声消除/波束成形 |
| 功放 | **MAX98357A 模块（I2S 数字功放）** | I2S 直出，无需 DAC |
| 喇叭 | **3W 8Ω 小喇叭** | 约 ¥5 |
| 屏幕 | **ST7789 1.54" IPS 240×240（SPI，带排针）** | 配 LVGL 学习；不用 SSD1306 黑白屏 |
| 交互 | 2~3 个按键（PTT/唤醒/音量）；**WS2812 灯环**（可选） | 状态指示，丰富外观 |
| 电源 | 早期 USB 供电；电池可选 TP4056 + 18650，画板时并入 | 后期再考虑 |
| 工具 | 电烙铁套装、万用表、面包板、杜邦线；KiCad、Fusion 360 | 3D 打印先代打，熟练后可自购 |

### 学习路线（里程碑）

- **L0 环境**：装 ESP-IDF，跑通例程，点亮 ST7789（LVGL Hello World）
- **L1 音频输入**：INMP441 采集 → 串口打印波形/音量
- **L2 音频输出**：MAX98357A 播放正弦波/录音回放
- **L3 飞线原型**：开发板 + 麦 + 功放 + 屏 全接上 → WebSocket 连远端 Agent 端到端对话
- **L4 画板集成**：KiCad 原理图 → PCB 布局布线 → 嘉立创打样 → 焊接 → 板级验证
- **L5 外观**：3D 建模外壳（考虑出声孔/屏幕开孔/散热）→ 3D 打印 → 装配
- **L6 收尾**：（可选）换主控/换屏幕重新集成，整机联调打磨

### 工具准备（按现状确认）

- **已有**：万用表
- **飞线阶段（L0~L3）**：面包板 + 杜邦线即可；买"带排针"模块可全程免焊接
- **画板前购置（L4 前）**：电烙铁套装（+ 焊台）；示波器建议后续再买（调 I2S/SPI 时序时最有用）
- **软件**：KiCad（免费）/ 嘉立创 EDA；Fusion 360（个人免费）/ FreeCAD
- **3D 打印**：先用第三方代打（嘉立创 3D 打印 / 淘宝代打），自购打印机暂不规划；PCB 打样走嘉立创（10×10cm 内很便宜，可顺带 SMT 贴片）

## 1. 项目定位

软硬件结合项目，实现一个 **Agent 硬件终端**：

- **Agent 本体运行在远端**（remote），负责智能对话、推理、工具调用等核心逻辑。
- **本终端 = UI 层 + 操作层**：负责本地感知（监听）、输出（发声、显示）、交互控制。

```
┌───────────────────────────┐        ┌───────────────────────────┐
│   终端硬件（本项目）         │        │   远端 Agent 服务          │
│                           │        │                           │
│  ┌─────────────────────┐  │  信令  │  ┌─────────────────────┐  │
│  │ UI 层（显示/状态/交互）│◄─┼────────┼─►│ Agent 核心逻辑        │  │
│  └─────────────────────┘  │        │  └─────────────────────┘  │
│  ┌─────────────────────┐  │ 音频流 │  ┌─────────────────────┐  │
│  │ 操作层（监听/发声/按键）│◄─┼────────┼─►│ 语音/LLM 服务        │  │
│  └─────────────────────┘  │        │  └─────────────────────┘  │
└───────────────────────────┘        └───────────────────────────┘
```

## 2. 终端四大能力（ESP32 落地）

| 能力 | 方向 | ESP32 实现 |
|------|------|-----------|
| 监听 Listen | 输入 | I2S 麦克风（INMP441）→ 16kHz 16bit PCM → WS 上送 |
| 唤醒 Wake | 输入 | ESP-SR WakeNet 离线唤醒词，唤醒后进入监听 |
| 发声 Speak | 输出 | 接收远端音频帧 → I2S → 功放/喇叭（MAX98357A + 3W 8Ω） |
| 显示 Display | 输出 | LVGL 小屏（状态/文本/动画）或 ESP32 内置 Web 页面 |
| 交互 Operate | 双向 | 按键/触摸/唤醒词 控制会话状态 |

## 3. 通信模型（建议）

- **控制/信令**：WebSocket（双向、低延迟、易扩展），承载事件与 JSON 消息。
- **音频流**：优先 WebSocket 二进制帧（Opus/PCM），避免二次连接；备选 RTP。
- **心跳/重连**：心跳保活 + 指数退避重连 + 断网状态上屏。

## 4. 已确认的关键决策

1. **硬件路线**：学习型 DIY——不买集成板；ESP32-S3-WROOM-1-N16R8 开发板 + 分体模块飞线验证，后期自绘 PCB 集成（可选换主控）。
2. **显示**：ST7789 1.54" IPS 小屏 + LVGL；Web 页面作为备选/扩展。
3. **远端 Agent 协议**：自研 WebSocket 协议（JSON 信令 + 二进制音频），以远端 Agent 实际实现为准。
4. **唤醒词**：ESP-SR 离线唤醒，先官方内置词，后续可训练自定义词。
5. **工具**：万用表已有；飞线阶段免焊接（带排针模块）；电烙铁 L4 前购置，示波器后续；3D 打印走第三方代打。

## 5. 后续里程碑（选型确认后细化）

- M0 项目骨架：目录结构、配置、日志、依赖管理
- M1 音频通路：采集 → 上送 → 接收 → 播放
- M2 信令通路：WebSocket 连接、会话生命周期、心跳重连
- M3 显示 UI：状态机 + 对话界面
- M4 联调与打磨：唤醒、降噪、低延迟、异常恢复
