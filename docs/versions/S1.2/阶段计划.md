# S1.2 阶段计划

## 1. 范围

本阶段先只连接 ST7789 屏幕，不同时连接功放、喇叭、麦克风或按键。

## 2. 顺序

1. **裸板构建**：构建 ST7789 SPI 固件，首次使用保守时钟和固定 3.3V 背光。
2. **基础点屏**：循环显示红、绿、蓝、白、黑，确认供电、SPI 和 RGB 顺序。
3. **方向图案**：显示不对称色块，确认上下左右、镜像和 240×240 有效区域。
4. **刷新稳定性**：重复刷新并检查花屏、阻塞、复位和 USB 稳定性。
5. **背光与 LVGL**：基础显示通过后，再确认 GPIO7 背光控制并接入最小 LVGL 状态页。

## 3. 停止条件

- 屏幕型号、供电电压或排针顺序与实物丝印不一致。
- 屏幕、开发板或导线异常发热、有焦味、USB 反复断连。
- 画面持续纯白、闪烁或花屏时先断电复核接线，不带电移动杜邦线。
- `BLK` 接口电流能力未确认前，不直接用 GPIO7 承担背光供电。

## 4. 完成判定

- RGB、白、黑及方向图案显示正确。
- 背光控制行为明确。
- 多次刷新无持续花屏、阻塞或重启。
- LVGL 最小状态页可以稳定显示。
