## 目录约定

每个阶段目录至少包含：

- `README.md`：阶段状态、范围、入口和当前结论。
- `阶段计划.md`：任务顺序、产出、风险和停止条件。
- `验收记录.md`：实际证据、偏差和阶段结论；未执行时明确写“待执行”。

阶段需要专用表单时可增加文件，例如 S1.0 的 `硬件核对表.md`。不得把计划命令、准备采购或
未验证的接线描述成已经完成。

## 状态约定

- `待启动`：尚未细化或未取得开始确认。
- `设计中`：正在收敛阶段范围和方案。
- `执行中`：已经开始实际检查、安装、制作或验证。
- `验收中`：计划任务已执行，正在核对证据。
- `已完成`：全部阶段门通过并记录证据。
- `已阻塞`：存在无法在当前授权或条件下继续的外部阻塞。

只有 `验收记录.md` 明确给出“通过”，总索引才能把阶段标记为 `已完成`。
