# S2.2 阶段计划

## 执行顺序

1. 封装单麦 AFE/WakeNet 生命周期，核验模型名、采样率、feed 块长和通道数。
2. 把 INMP441 的 I2S 32-bit 左槽转换为 PCM16，持续 feed/fetch 并记录唤醒事件。
3. 将唤醒与 PTT 汇合到同一本地提示、5 秒录音回放闭环；播放时暂停监听，结束后复位缓冲。
4. 构建并记录 app、内部堆、PSRAM 和模型余量，再烧录实机确认无 panic/看门狗。
5. 在 0.5～1 米安静环境执行 20 次“你好小智”，记录成功、漏检和延迟。
6. 保留至少 30 分钟背景声观察记录；统计完成前不关闭阶段。

## 停止条件

- AFE 报告模型、采样率、块长或通道数与单麦 16 kHz 基线不一致。
- 持续监听导致 PTT、屏幕、Wi-Fi 或本地回放回归。
- 播放提示音自触发、I2S 资源冲突、持续 ring buffer 溢出、看门狗或重启。
- 内部堆或任务栈余量无法解释，或连续监听出现单向持续下降。

## 阶段门

- 0.5～1 米安静环境 20 次唤醒至少成功 18 次，并记录模型与默认阈值。
- 30 分钟安静/日常背景声观察无误触发；该结果只代表当前原型。
- 唤醒与 PTT 均能触发一次本地闭环，播放结束后可靠恢复监听。
- Wi-Fi 和屏幕保持正常，无 panic、看门狗或不可恢复 I2S 错误。
