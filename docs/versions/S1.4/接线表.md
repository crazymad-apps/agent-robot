# S1.4 飞线整机接线表

> 改线或焊接前必须断开 USB。所有模块共地；屏幕和麦克风只能使用 3.3V。

| 模块 | 丝印/端子 | DevKitC-1 | 说明 |
|---|---|---|---|
| MAX98357A | `VIN` / `GND` | `5V` / `G` | USB 低功率验证范围 |
| MAX98357A | `BCLK` / `LRC` / `DIN` / `SD` | GPIO4 / GPIO5 / GPIO15 / GPIO16 | 录音时 GPIO16 强制为低 |
| 喇叭 | 已确认的一组 4Ω线圈 | 功放 `+` / `-` | 不接系统地 |
| INMP441 | `VDD` / `GND` | `3V3` / `G` | 禁止接 5V |
| INMP441 | `SCK` / `WS` / `SD` / `L/R` | GPIO4 / GPIO5 / GPIO6 / `G` | 左槽采样；与功放共享时钟 |
| ST7789 | `GND` / `VCC` / `SCL` / `SDA` | `G` / `3V3` / GPIO12 / GPIO11 | SPI 时钟与 MOSI |
| ST7789 | `RES` / `DC` / `CS` / `BLK` | GPIO8 / GPIO9 / GPIO10 / `3V3` | 背光仍固定开启 |
| PTT | 两个跨触点组引脚 | GPIO21 / `G` | 内部上拉、按下为低；无极性 |
| 音量加 | 常开按键 | GPIO1 / `G` | 飞线阶段不接；GPIO 保留到可靠载板或 PCB |
| 音量减 | 常开按键 | GPIO2 / `G` | 飞线阶段不接；GPIO 保留到可靠载板或 PCB |

四脚轻触开关的同组引脚常通。必须用万用表确认：松开时两脚断开、按下时导通，才可作为 GPIO 与 GND 的两个引出脚。
