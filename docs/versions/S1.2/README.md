# S1.2：显示验证

| 项 | 内容 |
|---|---|
| 状态 | 已完成：基础点屏、方向、刷新与 LVGL 状态页通过 |

## 目标

- 单独验证 1.54 英寸、240×240、ST7789 SPI 屏幕。
- 先以低速 SPI 完成纯色、色条、方向和刷新验证，再接入 LVGL 最小状态页。
- 首次测试把 `BLK` 固定接 3.3V；确认模块背光接口后再验证 GPIO7 PWM。

## 完成结果

1. `S1.2-display.1` 已完成 RGB、白黑、方向和重复刷新验证。
2. `S1.2-display.3` 已完成 LVGL 9.3.0 最小状态页并稳定驻留。
3. 首次背光采用 `BLK→3V3` 固定开启；GPIO7 PWM 未在缺少接口电流证据时直接驱动，留待增加合适开关级后验证。
