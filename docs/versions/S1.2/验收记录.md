## 2. 结论

- `S1.2-display.2` 首次实机运行在状态页创建后因 LVGL 运行于默认主任务的小栈而触发栈溢出并重启；`S1.2-display.3` 将 LVGL 初始化、页面创建和刷新全部移至独立 8KB 栈任务，已通过上述串口复验。
- 结论：ST7789 的供电、SPI、RGB 顺序、方向、固定背光、重复刷新及 LVGL 最小状态页通过。
- GPIO7 PWM 背光调节没有通过，不得引用本记录宣称已验证；后续使用开关级或取得模块电流证据后补验。
- 进入 S1.3：允许。
