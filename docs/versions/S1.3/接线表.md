# S1.3 INMP441 接线表

> 接线或改线前必须断开 USB。功放可以保留物理接线，但其 `SD(GPIO16)` 在固件中始终保持低电平。

| INMP441 丝印 | DevKitC-1 | 功能 |
|---|---|---|
| `VDD` | `3V3` | 3.3V 供电，不能接 5V |
| `GND` | `G` | 共地 |
| `SCK` | `GPIO4` | I2S BCLK |
| `WS` | `GPIO5` | I2S LRCLK/WS |
| `SD` | `GPIO6` | I2S 麦克风数据输出到主控 |
| `L/R` | `G` | 选择左声道；必须有确定电平，不能悬空 |

## 上电前检查

- `VDD` 接 3.3V，不能误接 5V。
- `L/R` 明确接地，不能悬空。
- `SD` 只接 GPIO6，不能与功放 `DIN(GPIO15)` 混淆。
- 麦克风拾音孔无遮挡，板背面不接触导电物。
