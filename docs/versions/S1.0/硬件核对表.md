## 5. S1.0 核对结论

- 硬件身份是否足以进入接线设计：开发板、显示屏、麦克风、功放和喇叭阻抗已足以进行受控原型接线；按键仍待核对。
- 供电和逻辑电平是否明确：显示与麦克风使用 3.3V，功放使用 5V 并与主控共地；显示 BLK 有效电平仍待实测。
- GPIO 是否无冲突：候选 GPIO 已用官方 v1.1 资料复核通过。
- S1.0 结论：通过；可进入 S1.1。
- 后续信息：UART 桥接口、麦克风芯片本体、喇叭额定功率、按键与辅材分别在需要它们的阶段继续核对；显示 BLK 电流和 PWM 方式在 S1.2 实测。
