# S2.3 阶段计划

## 执行顺序

1. 在不改变媒体行为的前提下增加最小诊断：启动和本地闭环后的内部堆/PSRAM 快照；其余复用现有 Wi-Fi、WakeNet 与错误日志。
2. 构建、烧录并先做冷启动回归，确认 Wi-Fi、屏幕、WakeNet 和 PTT 基线未回归。
3. 正常联网时各执行一次 WakeNet 与 PTT 本地闭环。
4. 在持续 `WAKE READY` 中断开 AP，在离线/退避重连期间各执行一次 WakeNet 与 PTT 本地闭环。
5. 恢复 AP，确认自动获取 IP 后再各执行一次 WakeNet 与 PTT，同时检查屏幕、重启与明确错误日志。
6. 对比前后内部堆/PSRAM 快照，记录功能结果；不在本阶段扩展为长时趋势或压力测试。

## 停止条件

- 基础快照显示内部堆/PSRAM 余量不足以执行已验证闭环。
- Wi-Fi 断开或重连导致 I2S 超时、WakeNet 不可恢复、黑屏、棕断或重启。
- 播放后不能回到 `WAKE READY`，或 PTT 在任一网络状态失效。
- 诊断日志泄露 Wi-Fi 密码或其他凭据。

## 阶段门

- Wi-Fi 正常、离线/退避重连和恢复状态下，WakeNet 与 PTT 各能完成一次本地闭环。
- 屏幕持续正常，网络抖动期间无 panic、看门狗、棕断、不可恢复 I2S 错误或持续音频中断。
- 应用尺寸、内部堆/PSRAM 快照、唤醒计数、Wi-Fi 重连与明确错误都有可核对记录。
- 本阶段只得出功能共存可行结论，不宣称长期稳定性或量产可靠性。
