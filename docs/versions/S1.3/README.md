## 目标

- 验证单个 INMP441 的 3.3V 供电、I2S 时钟和数据采集。
- 输出峰值、直流偏置和 RMS 诊断，确认拍手或说话时电平有明显变化。
- 将固定时长 PCM 导出为可在电脑播放和检查的 WAV 文件。

## 完成结论

1. `L/R→GND` 的左声道采样有效，右声道保持为零，符合接线预期。
2. 静音、说话和拍手均有可区分的电平响应，拍手瞬态接近满量程但未持续削波。
3. 已导出 16 kHz、单声道、PCM16、5 秒 WAV；主机校验为 80,000 帧且可播放。
4. 用户确认语音可辨识；原始电平偏低通过本地回放数字增益处理，不阻塞硬件验收。
